# 设计系统（DESIGN_SYSTEM.md）

## 核心视觉原则
- 东方哲学感
- 现代专业软件
- 安静与克制
- 高级而不浮华

## 色板
- 暖白：#F5F2EA
- 墨黑：#171817
- 墨青：#18201F
- 朱砂：#9D4935
- 青灰：#657875
- 古铜：#A88956

## 使用规则
- 主体背景以暖白为主
- 内容文字以墨黑为主
- 朱砂可作为强调色，但不要大面积使用
- 古铜仅作为少量点缀，不能主导界面
- 不允许使用霓虹紫、廉价渐变、炫彩大面积背景

## 组件原则
- 文字层级清晰
- 行距舒展，留白保留
- 表单统一风格
- 卡片统一圆角、边框、阴影层级
- 按钮统一视觉语言
- 空状态、加载状态、错误状态必须标准化

## 文字原则
- 语言必须专业、克制、稳重
- 禁止浮夸承诺
- 使用：倾向、信号、阶段、目前更支持、可能表现、需要进一步确认
- 禁止：最准、必发财、必离婚、大凶、100%准确

## 端适配
- 桌面端优先保证 1280px / 1440px 的舒适布局
- 移动端需适配 390px 左右宽度，不能出现横向溢出
